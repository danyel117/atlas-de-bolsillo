# Contribuir

1. Haz un fork y crea una rama con tu mejora.
2. Instala las dependencias con `npm ci` y ejecuta `npm run dev`.
3. Mantén la interfaz en español, el uso por teclado y la experiencia en celular.
4. Si cambias los datos, modifica `scripts/prepare-data.mjs`, ejecuta `npm run data` y conserva la atribución ODbL.
5. Ejecuta `npm test` y `npm run build`.
6. Abre una pull request explicando el cambio y cómo lo comprobaste. Incluye una captura móvil si cambia la interfaz.

Las correcciones cartográficas deben citar una fuente y explicar el criterio de asignación a regiones. Cada país debe tener un único identificador y un marcador visible. No añadas cuentas, seguimiento ni servicios de pago sin discutir antes su necesidad.
