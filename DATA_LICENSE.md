# Data attribution

Application code is licensed under MIT. The data licenses below apply separately.

- `src/countries.json` is adapted from [mledoze/countries](https://github.com/mledoze/countries), npm `world-countries@5.1.0`, under [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1.0/), reproduced in `LICENSE-ODbL`. This adapted database is also distributed under ODbL 1.0. The preparation script selects UN members plus Palestine and Vatican City, Spanish common names, identifiers, coordinates, and one gameplay region per country. Russia uses a European locator; Cyprus is assigned to Asia. The database is provided in editable JSON in the public repository.
- `public/world-50m.json` is from [world-atlas@2.0.2](https://github.com/topojson/world-atlas), derived from [Natural Earth](https://www.naturalearthdata.com/), whose cartographic data is [public domain](https://www.naturalearthdata.com/about/terms-of-use/).
- DM Sans and Manrope fonts are delivered by Google Fonts under the SIL Open Font License.

Maps use simplified borders and Natural Earth's cartographic treatment of disputed areas. They are educational and do not imply a political position.
